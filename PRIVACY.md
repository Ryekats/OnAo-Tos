# Privacy Policy for On Ao Music Studio

Last Updated: [Tanggal Hari Ini]

## 1. Data We Collect
On Ao Music Studio only collects data necessary for its core functionality as a music bot. This includes:
- Server IDs (Guild IDs)
- Channel IDs (for music commands and queue)
- User IDs (for command execution and queue management)

We **DO NOT** store, log, or read any message content. We only process message content temporarily to execute user commands (like `!play` or `/play`), and it is immediately discarded after the command is processed.

## 2. How We Use Data
The collected data is used strictly to:
- Play music in your voice channel.
- Manage the music queue.
- Ensure the bot functions correctly (e.g., Anti-Disconnect features, 24/7 mode).

## 3. Data Sharing
We do not sell, trade, or share any collected data with third parties. All data is stored securely and only used for the bot's operation.

## 4. User Rights
Users can request the deletion of their data (such as clearing their music queue) by using the bot's commands or by contacting the developer.

## 5. Contact
If you have any questions, please contact the developer via GitHub or Discord.
